# Outputs

Saved model artifacts and figures live here.

## Layout

- `inference/` stores posterior objects, posterior samples, and calibration metadata.
- `tarp/` stores the TARP coverage tensor and publication figures.
- `simulations/` stores posterior predictive summaries, trajectories, and diagnostic plots.
- `ordering/` stores region and commune ordering summaries and plots.

These files are kept in stage-specific folders so the workflow stays easy to inspect and share.
