# Population GLW3 Extraction

This folder contains the population extraction work derived from GLW3.

## Contents

- GIS data used in the population extraction workflow.
- Dataverse source folders for the GLW3 population products.
- The R script and spreadsheet used to assemble the commune-level population inputs.

## How it connects

- The output is a supporting population input for the metapopulation model.
- It sits upstream of the retained modeling workflow.

## Notes

- Keep this folder as the reference archive for the population extraction work.
